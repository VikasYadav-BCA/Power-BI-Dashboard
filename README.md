# Power-BI-Dashboard
# Data Visualization Dashboard using Power BI

## Project Overview
This project is a Data Visualization Dashboard created using Microsoft Power BI. It helps to analyze and visualize city-wise data through interactive charts and graphs.

## Key Features
- City-wise Data Analysis
- Bar Chart Visualization
- Line Chart Analysis
- Stacked Column Charts
- Funnel Chart
- Scatter Plot Analysis
- Interactive Data Tables

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- Data Visualization

## Cities Analyzed
- Mumbai
- Kolkata
- Pune
- Lucknow
- Jaipur
- Delhi
- Hyderabad
- Ahmedabad
- Bengaluru
- Chennai

## Project Objective
The main objective of this project is to understand data patterns, compare different cities, and present meaningful insights using Power BI visualizations.

## Skills Learned
- Data Visualization
- Data Analysis
- Dashboard Creation
- Working with Charts and Graphs
- Power BI Reporting

This project helped me improve my Power BI skills and understand how to transform raw data into meaningful visual insights.
